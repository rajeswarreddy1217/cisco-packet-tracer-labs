# DHCP Network – Cisco Packet Tracer

## 🎯 Objective

Configure a router as a DHCP server and automatically assign IP addresses to multiple PCs.

## 🖥️ Devices

* 3 PCs
* 1 Cisco 2960 Switch
* 1 Cisco Router

## 🌐 Network

* Network: `192.168.10.0/24`
* Default Gateway: `192.168.10.1`
* IP addresses assigned automatically using DHCP

## 🔧 Configuration

The router was configured as a DHCP server to automatically provide IP addresses, subnet masks, and the default gateway to the PCs.

## 🧪 Testing

Ping was used to verify communication between the PCs.

## ✅ Result

Successfully configured DHCP and automatically assigned IP addresses to all three PCs.

## 📚 What I Learned

* How DHCP works
* How a router can act as a DHCP server
* Automatic IP address assignment
* Basic network connectivity testing
