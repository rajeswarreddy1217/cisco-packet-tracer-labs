# Basic LAN – Cisco Packet Tracer

## 🎯 Objective

Create a basic LAN using two PCs and a switch.

## 🖥️ Devices

* 2 PCs
* 1 Cisco 2960 Switch

## 🌐 IP Addressing

* PC0: `192.168.1.10`
* PC1: `192.168.1.20`
* Subnet Mask: `255.255.255.0`

## 🧪 Testing

Ping was used to verify connectivity between PC0 and PC1.

## ✅ Result

Successfully established communication between both PCs.
